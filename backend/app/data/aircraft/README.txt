types.json maps an ICAO aircraft type designator to "<ICAO class> <wake category>", for example B738 -> "L2J M"
(landplane, two jet engines, medium). It is derived from the aircraft type table of tar1090-db
(https://github.com/wiedehopf/tar1090-db), itself built on ICAO Doc 8643 and the Mictronics aircraft database.
